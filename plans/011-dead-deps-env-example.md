## Why this matters

Two dependencies in `package.json` have zero imports across the entire
codebase: `@types/three` (devDependency, ~600KB of type definitions) and
`web-tree-sitter` (dependency, ~1MB+ WASM parser). They add unnecessary install
weight and mislead contributors. Additionally, `.env.example` only documents
one environment variable (`GLOOMBERB_API_URL`) but the codebase reads
`GLOOMBERB_LANG` and `GLOOMBERB_CLOUD_HOSTED` — undocumented environment
variables that affect runtime behavior.
